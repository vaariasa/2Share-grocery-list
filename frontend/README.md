# Grocery List – Frontend

Angular 22 single page application (TypeScript + SCSS) for the Grocery List API.

```bash
npm install
npm start        # http://localhost:4200
npm run build    # production build in dist/
```

The API URL is configured in [`src/environments/environment.ts`](src/environments/environment.ts).

See the [main README](../README.md) and the [architecture documentation](../docs/architecture.md)
for the full picture.
